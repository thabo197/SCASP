# Stage 0 Inception Demonstration (5 minutes)

| Time | Topic | What to show and say |
|---|---|---|
| 0:00 to 0:30 | Problem and users | The one-page problem definition in `docs/charter.md`: who the platform serves and why one integrated platform helps |
| 0:30 to 1:30 | Requirements | `docs/requirements.md`: 16 functional and 12 non-functional requirements, their priorities, and the stages that build them |
| 1:30 to 3:00 | Architecture | `docs/architecture/architecture-baseline.md`: the context diagram, the module diagram with its dependency rule, and the domain model with its invariants |
| 3:00 to 4:00 | Repository and process | The repository on GitHub: protected `main`, the issue board with one issue per stage, the pull request template, `CONTRIBUTING.md` and the risk register |
| 4:00 to 5:00 | Live build | Run `mvn clean verify` and then `java -cp core-domain/target/classes edu.scasp.core.Main`, showing a successful build, passing tests and the banner |

Each member should present one part and be ready to explain it.
